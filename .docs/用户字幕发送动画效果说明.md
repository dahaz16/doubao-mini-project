# 用户字幕发送动画效果说明

## 📋 功能概述

实现了更加生动的用户字幕发送动画效果，营造出"消息发送"的视觉反馈。

## 🎬 动画效果详解

### 1. 点击"发送"按钮后（0.5秒过渡动画）

**三个同步动画效果：**

1. **背景淡出** 
   - 白色背景透明度：`rgba(255, 255, 255, 0.9)` → `rgba(255, 255, 255, 0)`
   - 阴影消失：`box-shadow: 0 4px 8px rgba(0, 0, 0, 0.25)` → `none`

2. **文字半透明**
   - 文字透明度：`opacity: 1` → `opacity: 0.5`

3. **向上移动**
   - 整体向上移动：`transform: translateY(-40rpx)`
   - 使用 `rpx` 单位确保不同机型物理距离一致（约 20px）

### 2. 点击"讲述"按钮后（无动画，直接重置）

**字幕回到原位并清空：**
- 位置重置：`transform: translateY(0)`
- 文字透明度重置：`opacity: 1`
- 背景恢复：`rgba(255, 255, 255, 0.9)`
- 内容清空：`userInput = ''`

## 🔧 技术实现

### CSS 关键样式

```css
/* 正常状态 */
.user-subtitle-scroll {
  background: rgba(255, 255, 255, 0.9);
  box-shadow: 0 4px 8px rgba(0, 0, 0, 0.25);
  transform: translateY(0);  /* 默认位置 */
}

.user-subtitle-text {
  opacity: 1;  /* 默认完全不透明 */
  transition: opacity 0.5s ease;
}

/* 淡出状态（发送后） */
.user-subtitle-scroll.fading {
  background: rgba(255, 255, 255, 0) !important;
  box-shadow: none !important;
  transform: translateY(-40rpx);  /* 向上移动 */
  transition: background 0.5s ease, box-shadow 0.5s ease, transform 0.5s ease;
}

.user-subtitle-scroll.fading .user-subtitle-text {
  opacity: 0.5;  /* 半透明 */
}
```

### JS 状态控制

```javascript
// 点击发送：触发淡出动画
handleMicToggle() {
  if (this.data.status === 'recording') {
    this.setData({ 
      status: 'idle',
      userSubtitleFading: true  // 触发淡出
    });
  }
}

// 点击讲述：清空字幕并重置状态
startRecordingLogic() {
  this.setData({
    userInput: '',              // 清空内容
    userSubtitleFading: false   // 重置淡出状态（自动回到原位）
  });
}
```

## 🎯 用户体验流程

```
1. 用户点击"讲述" 
   ↓
2. 开始录音，ASR 实时显示字幕（白色背景，完全不透明）
   ↓
3. 用户点击"发送"
   ↓
4. 【0.5秒动画】背景淡出 + 文字半透明 + 向上移动
   ↓
5. 字幕保持在半透明状态，可滑动查看
   ↓
6. 用户再次点击"讲述"
   ↓
7. 字幕瞬间回到原位并清空，开始新一轮录音
```

## 📐 设计参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 动画时长 | 0.5s | 所有动画统一时长 |
| 缓动函数 | ease | 平滑过渡 |
| 向上移动距离 | -40rpx | 约 20px 物理距离 |
| 文字透明度 | 0.5 | 半透明效果 |
| 背景透明度 | 0 | 完全透明 |

## ✅ 测试检查点

- [ ] 点击发送后，背景在 0.5 秒内平滑淡出
- [ ] 点击发送后，文字在 0.5 秒内变为半透明
- [ ] 点击发送后，字幕整体向上移动约 20px
- [ ] 发送后的字幕仍然可以滑动查看
- [ ] 再次点击讲述时，字幕瞬间回到原位并清空
- [ ] 不同机型上移动距离保持一致（rpx 单位）
- [ ] 取消录音时，字幕正确清空且状态重置

## 🎨 视觉效果

**发送前（录音中）：**
```
┌─────────────────────┐
│ 这是用户说的话...    │  ← 白色背景 (opacity: 0.9)
│                     │  ← 文字完全不透明
└─────────────────────┘
```

**发送后（0.5秒动画）：**
```
                       ↑ 向上移动 40rpx
┌─────────────────────┐
│ 这是用户说的话...    │  ← 背景透明 (opacity: 0)
│                     │  ← 文字半透明 (opacity: 0.5)
└─────────────────────┘
```

**再次点击讲述：**
```
┌─────────────────────┐
│ (清空)              │  ← 瞬间回到原位
│                     │  ← 重新开始显示新内容
└─────────────────────┘
```
